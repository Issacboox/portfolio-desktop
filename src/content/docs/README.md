# Documents for the AI

Drop Markdown (`.md`) or text (`.txt`) files in this folder and the Terminal's AI will read them,
answer from them, and cite them as sources. This README itself is ignored.

Good things to add:

- A longer bio, or answers to common recruiter questions ("Why the UK?", notice period)
- Project write-ups and case studies
- Notes you want the AI to know but not show elsewhere on the site

Tips:

- Start each file with a `# Title`. It's used as the source name.
- Use `##` headings. Each section becomes its own passage, so answers can cite the exact part.
- Everything here is public: visitors can get the AI to quote it. Don't put anything private in this folder.
